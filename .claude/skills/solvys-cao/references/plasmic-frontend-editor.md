# Legacy Visual Editor Contract

## Role

Plasmic is a protected legacy frontend editor and provisional composition input
when TP explicitly selects it. New frontend design, implementation checks, and
human review use the project ChatGPT Site.

Plasmic does not become current design authority by default. The project
ChatGPT Site is the frontend sandbox, implementation-check, and human-review
surface. Localhost and port 7777 are not acceptance proof.

## Required sequence

For an explicitly selected legacy Plasmic transfer:

1. Read the anti-slop law, shared `Design.md`, repo-local design canon, source
   components, and the active brief.
2. Record and verify the installation foundation: BeUI Pro primary with BeUI
   fallback; Motionary.dev secondary with ascertainty UI fallback; Bklit for
   data visualization with EvilCharts fallback. Include source, version,
   license, registry access, owner, and proof requirement.
3. Install or confirm the eligible library before implementation. Search the
   primary source and its fallback for the required block.
4. Assemble the approved block in Plasmic. Do not design a generic component or
   block when a suitable library block exists.
5. If no approved block fits, record a no-fit exception with the searched
   sources, reason, owner, maintenance cost, and TP approval before creating a
   custom block.
6. Review the Plasmic project with TP and record the accepted page, component,
   state, token, and behavior decisions. TP owns palette, effects, spacing
   adjustments, and polish.
7. Keep the accepted Plasmic result isolated from product source until TP
   authorizes source transfer.
8. Run source checks, build, and ChatGPT Site verification. Open
   `human-review` automatically when visual or content review is needed.
   Plasmic proof does not replace source, Site, deployed, or installed proof.
   Any resulting Site must still satisfy the 1:1 runnable prototype contract,
   with real copy, states, controls, responsive behavior, and provenance. A
   placeholder or fake Site cannot pass because Plasmic was selected.

## Concurrent Human Work

TP may edit Plasmic while the agent builds. Treat those edits as a separate
human lane:

- Do not revert, merge, normalize, or claim human changes unless TP explicitly
  brings them into the agent-owned scope.
- Continue against the agent's selected project, page, component, and source
  scope while disregarding unrelated human mutations.
- Present agent-owned and human-owned changes as separate candidates until TP
  chooses the source-bound result.

## Applicability

Do not use Plasmic for new screens, layout changes, component compositions,
visual states, responsive intent, or interaction prototypes. Use the project
ChatGPT Site for those changes. Use this legacy path only when TP explicitly
selects a Plasmic source transfer with a bounded page, component, state, and
owner.

Every explicitly selected legacy transfer records:
