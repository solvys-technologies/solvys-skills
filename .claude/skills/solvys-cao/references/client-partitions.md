# Client And Product Partitions

Solvys products share operating quality, not one visual costume. The CAO must name the partition before importing design, stack, copy, or workflow precedent.

## Universal Solvys Layer

- Problem-first solution ownership.
- Repo/runtime truth and dirty-state preservation.
- Best-work precedent and exact-source reuse.
- Borderless, purposeful controls; coherent visual world; authored interactions.
- Evidence-gated completion and durable learning promotion.
- Direct, respectful communication.

## Product Partitions

- **Fintheon:** dense research/trading cockpit, cloud-backed operating model, live-data cadence, protected fuses/charts/positions, EdgeCaster geometry, provider/release/install truth.
- **Solvys studio and shared skills:** runtime-neutral operating doctrine, client boundaries, reusable process, stack and design canon. Do not hard-code one agent vendor as the company identity.
- **SSFitness / Stryv Society Fit:** mobile-first local commerce, booking and billing truth, direct athletic conversion, authenticated member flows, Cloudflare/Next operating constraints.
- **HeirRight / HWRITE:** estate workflow language, operator trust, production-loop proof, Podio and document/integration boundaries, no casual invention of legal workflow semantics.
- **Purpose:** full-screen personal operating environment, existing weather/background continuity, real backend contracts, no generic dashboard refactor.
- **Client websites:** begin with supplied inspiration fidelity, then build a distinct client identity through lawful assets, client content, and a recorded divergence pass.

## Transfer Test

Before reusing a pattern, label it:

- **Universal:** the mechanism improves any Solvys project.
- **Register:** it belongs to a class of surfaces, such as dense product UI or cinematic public site.
- **Product-specific:** it depends on this product's state, vocabulary, data cadence, or geometry.
- **One-off:** it solved one moment and should not become a default.

Never transfer product-specific semantics merely because the visual result was successful.
