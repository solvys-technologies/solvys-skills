# Project records stay local

The public skills suite does not publish client paths, task IDs, provider IDs,
account identities, live branches, or custody state.

Create each live project record from `factory/Factory Registry/Templates` and
store it in the team's protected Codebase Cabinet or the installer-created
`~/.config/solvys-factory/projects` directory. The project Welcome Mat points
agents to that protected record before work begins.
