## What the demo should prove

- The agent can extract the catalyst.
- The agent can name affected instruments.
- The agent can classify signal type and time sensitivity.
- The agent can update narrative, timeline, catalyst queue, risk/regime, and desk plan.
- The agent preserves provenance and flags human review when confidence is limited.
